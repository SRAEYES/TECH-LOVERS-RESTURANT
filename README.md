# 🍽️ Tech Lover's Restaurant Billing System

Welcome to **Tech Lover’s Restaurant**, a terminal-based invoice generation system crafted **specially for tech enthusiasts like you**!  
Whether you're an aspiring programmer or a hungry coder craving automation, this project simulates how a real-world restaurant billing system operates — **with login authentication**, **dynamic bill generation**, **discounts**, **taxes**, and **invoice tracking**, all through the magic of **C programming**.

---

## 🔧 Features

-> **User Login System**  
Only registered users can access the billing functionality. Login credentials are predefined for simplicity.

-> **Generate Invoice**  
Create invoices with customer names, item quantities, unit prices, and auto-calculated totals.

-> **Formatted Billing Output**  
Stylish bill headers, neatly formatted item tables, subtotal, discounts, CGST, SGST, and grand total — printed right in the terminal.

-> **Store Multiple Invoices**  
Save multiple invoices during the session for future lookup.

-> **Search Invoice by Customer Name**  
Retrieve any previously saved invoice by customer name.

-> **Exit Safely**  
A polite goodbye when you're done. Because tech should always be kind.
